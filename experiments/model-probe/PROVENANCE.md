# Проба: как модель пишет модуль сама

**Когда:** 17.10.2026
**Как получено:** нейтральный одноразовый запрос через `hermes chat -q` — модель (deepseek-v4.1-flash:cloud в обвязке Hermes) получила задачу «напиши полный рабочий код python-модуля taskqueue.py: очередь задач на SQLite — поставить задачу, снять следующую в работу, повторы с экспоненциальной задержкой, статистика по состояниям» **без единого слова про контракты, секции, докстринги и тесты**. В обвязке с инструментами модель записала модуль в файл сама.

**Файл `probe_taskqueue.py`** — дословный результат пробы (571 строка). Это артефакт-доказательство, а не продакшн-код и не пример стиля репозитория.

**Что показала проба** (проверяется скриптом `analyze_probe.py`):

| наблюдение | значение |
| --- | --- |
| строк | 571 |
| шапка-контракт модуля (докстринг с назначением, оговорками и примером вызова) | есть |
| секционных комментариев | 7 (`инфраструктура`, `постановка`, `съём в работу`, `завершение`, `служебное`, `статистика`, `воркер-хелперы`) |
| функций `def` | 28 |
| из них с докстрингом | 7 (≈25 %) — именно нетривиальные: `backoff`, `_tx`, `complete`, `stats`, `enqueue_many`, `due_in`, `requeue_all_failed` |
| тестовый код | в самом модуле нет, но модель **сама** написала отдельный тестовый файл на 250 строк, прогнала его, поймала падение и поправила модуль |

**Зачем это в репозитории:** проба — независимое подтверждение двух тезисов разбора `../../references/sft-code-training-and-module-contracts.md`: (1) «шапка модуля + секции + докстринги только на сложном» — природное поведение модели, его достаточно окультуривать; (2) в агентной обвязке модель немедленно восстанавливает цикл «написал → прогнал → поправил», поэтому приказ «тестируй» не добавляет ей ничего нового, а контракт нужен там, где петля исполнения недоступна или дорога.

**Гигиена пробы (для повторения):** в агентной обвязке модель пишет файлы на диск (в том числе в домашний каталог) — артефакты убирать; stdout забит патчами и декором CLI, поэтому анализировать нужно записанный файл, а не вывод.
