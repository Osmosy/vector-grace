# Замер предикатов на посаженных дефектах

Набор: пять дефектов по классам из `references/semantic-invariants-soft-logic.md` §4 —
подменённый коэффициент, инвертированное условие, пропущенная граница, неверный
порядок вызовов, потерянная ветка отказа. Чистый вариант — `clean.py`, подменяемый
файл — `src/upload.py`, переход `retry_on_upload`.

| предикат | поймано | пропуск | ложное отклонение | чистый код |
|---|---|---|---|---|
| v1 `checkers/check_retry.py` — поиск подстрок | 1 / 5 | 0.8 | 0.0 (1 прогон) | проходит |
| v2 `checkers/check_retry_ast.py` — разбор AST | 5 / 5 | 0.0 | 0.0 (1 прогон) | проходит |

Сырые отчёты: `report-v1.json`, `report-v2.json` (`grace.py measure --json`).
Воспроизвести: `python3 ../../grace.py --root . measure --inv INV-0001 --by <кто>`.

## Что числа значат

- **v1 видит только удаление повтора целиком.** Строковый предикат проверяет
  наличие `range(attempts)` и `except OSError`; коэффициент, возвраты, порядок
  вызовов и ветка исчерпания для него невидимы. Это ровно тот случай, когда
  зелёный чекер создаёт ложное чувство проверки.
- **v2 проверяет структуру.** Запас повторов не меньше трёх, цикл по
  `range(attempts)`, `send` внутри `try` с обработкой `OSError`, успех возвращает
  `True`, исчерпание — `False` после цикла.
- **Замер поймал дефект в самом предикате.** Первая версия v2 отклоняла чистый
  код (`false_reject = 1.0`): проверка хвостового `return False` смотрела в тело
  цикла вместо тела функции. Без замера этот предикат попал бы в приёмку и
  покрасил бы каждый корректный модуль. Ложное отклонение дороже пропуска:
  агент начинает «чинить» правильный код.

## Чего числа не значат

- **v2 писался с оглядкой на этот же набор дефектов.** 5 из 5 здесь — оценка
  сверху, а не измерение обобщения: набор перестал быть отложенным в тот момент,
  когда по нему правили предикат. Честное число требует второго набора, который
  предикат не видел.
- **Ложное отклонение измерено на одном чистом варианте** (`clean_runs = 1`).
  Для устойчивой оценки нужны несколько чистых вариантов: рефакторинг без
  изменения поведения, переименования, другой стиль.
- **Пять классов дефектов — не все классы.** Дефект вне списка не проверялся
  никем; это граница замера, а не свойство предиката.
- **v2 не зарегистрирован.** Он остаётся кандидатом: регистрация — новая версия
  чекера с новым `sha256` и новое доказательство, иначе `replay` обязан отказать
  (иначе приёмка тихо проверит другим кодом, чем записано).
