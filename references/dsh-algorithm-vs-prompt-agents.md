# Алгоритм вместо промпта: старые агенты не догоняют DSH — вопрос в том, выживут ли они

> Эссе автора GRACE (Владимир Иванов, август 2026). Развивает линию
> `plugin-everything-deepseek.md` и `dsh-cordis-self-modification.md`:
> сравнение DSH не с точки зрения фич, а с точки зрения экономики
> исполнения агентской дисциплины. Блок «Верификация» — редакторская
> вставка с фактами по состоянию на 28.08.2026, не текст автора.

## Тезис: вопрос не в сближении, а в выживании

Не стоит вопрос о том, что старые агенты (Codex, Claude Code и
подобные) как-то приближаются к потенциалу DSH. Вопрос стоит иначе:
**выживут ли многие из них**. DSH уже набрал звёзд больше большинства
популярных агентов кодирования — за две недели с момента публикации.

## DeepSeek сам работает на DSH

Сам DeepSeek разрабатывает DSH на DSH: в репозитории лежат их
внутренние скилы (`.agents/skills/`) — код-ревью, доки, pre-push
проверки, слияние стековых PR и т.д. Команда ест собственную собачью
еду, и это лучший маркер серьёзности проекта.

Если до появления DSH и использовался чужой агент (например, Codex) —
то только как временное решение, пока не было своего. Это довольно
очевидно: смысл иметь ещё один агент, когда есть DSH, около нуля. При
этом DSH легко интегрируется с другими агентами, так что сохранение
чужих конфигов в репо (`.claude/`, `AGENTS.md`) — скорее про
сохранение наработок, чем про реальную зависимость.

## «Чатики агентов» против подписок на события

Обычные мультиагентные решения (Agent Teams и подобные) намного слабее
DSH — это по сути «чатиков агенты»: агенты общаются друг с другом
переменными порциями текста, и вся координация живёт в промптах.

В DSH координация — это **подписки на события**, причём через плагины,
которые создаются на лету. Плагин — это алгоритм, а алгоритм априори
может намного больше любой фиксированной функциональности.

## Экономика дисциплины: алгоритм ≠ промпт

Ключевое различие — как исполняется обязательная агентская дисциплина
(TDD, проверки перед коммитом, ритуалы ревью, порядок работы):

- В Codex или Claude Code дисциплина **каждый раз оплачивается
  токенами**: модель читает инструкцию, удерживает её в контексте и
  исполняет вероятностно. Есть лишь некоторая вероятность, что LLM
  исполнит требуемый алгоритм через промпт — и каждая итерация контроля
  стоит времени и денег.
- В DSH та же дисциплина **один раз зашивается в плагин**. Это не
  промпт, а код: он работает всегда, а не «с некоторой вероятностью».

Следствия: это не только дешевле в токенах — это надёжнее и быстрее
**на порядки**. ИИ работает медленно; зашитый алгоритм исполняется
детерминированно и мгновенно. LLM в такой архитектуре занимается тем,
для чего нужна: тем, что нельзя выразить алгоритмом, — а всё
формализуемое уходит из промпта в код.

## Следствие: гонка не в потенциале, а в выживании

Старые агенты могут добавлять те же фичи — скилы, субагентов, хуки. Но
пока дисциплина исполняется промптами, они платят вероятностный налог
на каждом шаге. DSH снял этот налог архитектурно. Догонять
функциональностью можно, догонять архитектурой — нельзя: её надо
перестраивать, а это уже другой продукт.

  порогом входа, дистрибуцией и экосистемой.

  (адаптеры — тоже плагины, тезис «всё — плагин» соблюдён буквально).
- Дистрибуция с нулевым трением: плагин = npm-пакет с ключевым словом
  `dsh-plugin` или топиком на GitHub; установка `npx @deepseek-ai/dsh
  plugin add`. Реестр индексируется сам, сайт статический.

Что это добавляет к тезису о выживании:

1. **Сетевой эффект заработал раньше, чем у конкурентов появилась
   реакция.** 3,3K плагинов за две недели — это не фичи, это экосистема:
   гонка смещается с «у кого больше фич» на «вокруг кого растёт
   комбинаторика плагинов».
2. **PTC стал официальным пресетом.** На сайте пресет «PTC — код как
   вызовы инструментов»: инструменты вызываются программой на
   TypeScript, «целая программа за один шаг» вместо выбора по одному.
   Коммиты 26-27.08 (переименование code mode → ptc) — это не
   эксперимент, а продуктовая ставка. Тезис «алгоритм вместо промпта»
   возведён в название режима.
3. **«Чатики агентов» подтверждены контрпримером изнутри**: в реестре
   есть dsh-agent-squad (капитан, участники, задачи с зависимостями) —
   но реализован он как плагин с монитором дерева задач и обменом
   сообщениями через рантайм, т.е. даже мультиагентщина в DSH — это
   подписки на события, а не переписка промптами.
4. **Порог входа — единственный бастион старых агентов**, и его тоже
   штурмуют: в реестре десяток десктоп-оболочек (dsh-desktop в трёх
   вариантах, установщик 5 МБ, TUI-скины), мобильные клиенты, рынок
   плагинов в один клик. Конфигурационную сложность — главный
   контрапункт — закрывают плагины, которые прячут конфигурацию.

Заметное для нашего стека: dsh-im (IM-боты к DSH: Telegram, Slack,
Discord, WeChat и др. по QR), dsh-ears (голосовой ввод с локальным GPU
Whisper — перекрывает часть сценария Voice-Transcriptor прямо в
агенте), dsh-deja (поиск по прошлым сессиям без LLM и эмбеддингов —
локальный бинарник), пул памяти (MemOS, mnemon, graph-memory,
OpenViking), harnessrouter (Unified Harness Protocol: Codex, Claude
Code, Hermes, DSH через один API — прямое подтверждение «DSH легко
интегрируется с другими агентами»).

## Выводы для GRACE

1. **Дихотомия «промпт vs алгоритм» — ключевая**: дисциплина, которую
   LLM исполняет вероятностно за токены каждый раз, должна быть
   зашита в код один раз. Это то же правило, что intelligence vs
   judgment (см. `agent-project-viability.md`): формализуемое — в
   алгоритм, LLM — только на неформализуемое.
2. **Событийная шина против «чатиков агентов»** — архитектурный
   критерий зрелости агентских платформ: координация текстом — признак
   прототипа, координация подписками на события — признак системы.
3. **Звёзды ≠ выживание**. DSH уже в топе по звёздам, но судьбу старых
   агентов решат порог входа, дистрибуция и способность вбирать
   плагин-парадигму. Скилы Claude Code — шаг в ту же сторону, но без
   event bus и mount/unmount это паллиатив.
4. **Главный риск DSH** остаётся прежним: конфигурационная сложность
   при 49 пакетах и плагин-конфликты. Граница пролегает там, где
   конфигурацию берёт на себя сам ИИ (генерирует композицию профиля),
   а не человек.
5. **РФ-факт**: DSH — один из немногих крупных агент-харнессов,
   работающих без VPN (DeepSeek API доступен).
