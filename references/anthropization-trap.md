# Anthropization trap: почему пайплайны ломаются на средних LLM

> Автор: Vladimir Ivanov (@turboplanner)
> Контекст: разбор неудачного пайплайна команды, где DeepSeek не справился

## Тезис

Главная ошибка — антропизация процесса разработки с агентами. Команды повторяют схему работы людей: "человек пишет ТЗ → агент исполняет". Для агентов это субоптимально.

## Принципиальная ошибка

У людей обязательно "ТЗ". У агентов нормально передавать прототип с комментариями. Очень часто прототип работает лучше, когда спецификация слабая.

Если DeepSeek не делает что надо — спецификация слабая. Не DeepSeek плохой, а промпт плохой.

## Внедрённая документация

Документация должна быть в коде, не в отдельном файле:
- Код прошит тегами (GRACE semantic markup), не просто болтовнёй в комментариях
- Логи прошиты тегами `[Module][function][BLOCK_NAME]`, не свободным текстом
- Всё, что агент должен знать о коде, — в самом коде

Внешняя документация (MD-файлы, спеки на естественном языке) — деградирует. Агенты игнорируют её в ~50% случаев. Встроенная разметка — 100% прочтения.

## Переоценка компетенции

Крупная LLM (Claude, GPT-4, Gemini) работает с кривейшим пайплайном — каждый дурак может его заставить работать. Это создаёт ложную уверенность.

Тестирование пайплайнов ведут на средних LLM (DeepSeek, GLM, Claude Haiku), т.к. кривизна сразу всплывает. Если сломалось на средней LLM — пайплайн кривой, не модель. У крупной LLM тоже будет деградация от этих же причин, но мягче — и это проблема, потому что она незаметна.

## Конструктивный подход

Когда сломалось — смотреть почему:
1. Спецификация слабая? → заменить ТЗ на прототип с семантикой
2. Документация внешняя? → внедрить в код
3. Логи без тегов? → прошить BLOCK_NAME маркеры
4. Пайплайн антропоморфен? → перестроить под агентскую модель

Не винить модель. Винить пайплайн.

## Связь с GRACE

- Semantic markup = внедрённая документация, не внешняя
- Prototype pipeline = агентская модель, не антропная
- Haiku test = диагностика кривизны пайплайна
- "Разметка — leverage" = правильный пайплайн поднимает среднюю LLM до крупной
